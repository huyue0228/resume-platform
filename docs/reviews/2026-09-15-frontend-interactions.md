# 前端交互审查与改造记录

日期：2026-09-15

## 结论

本轮按页面和公共组件审查了导航、数据维护、候选人详情、任务与计划、系统配置及 W3 认证入口。改造重点是统一操作方式、明确修改范围、保留错误反馈和权限边界。继续使用当前 React、Ant Design 与 ProComponents 的组件体系，将维护表单改为抽屉并集中实现表格交互。

## 审查结果与处理

| 范围 | 发现的问题 | 本轮处理 |
| --- | --- | --- |
| 岗位、院校、部门人员授权 | 逐行编辑和删除常驻；没有统一批量修改 | 名称可点击进入编辑抽屉；操作收进更多菜单；勾选后显示批量操作栏 |
| 用户、角色、院校标签、准入规则、专业词表 | 各表维护方式分散 | 接入相同批量侧边栏与抽屉表单，保留内置账号保护和角色权限范围 |
| 岗位接收状态 | 只能逐条修改 | 批量接收设置快捷入口，必须填写状态和原因，每条沿用自己的状态版本校验 |
| 公共表格 | 操作列占用较大空间；部分入口缺少键盘语义 | 操作列收窄为更多图标；桌面悬停或键盘聚焦显示，小屏保留入口；菜单支持键盘访问 |
| 任务列表、任务卡片、定时计划、需求供给 | 同类操作仍直接排列在表格或卡片中 | 复用更多菜单；完成的任务不显示空操作入口 |
| 批量修改 | 容易把空值误作清空；难以确认范围；失败后缺少处理依据 | 字段选择、明确清空、记录清单、修改摘要、真实完成计数、逐条失败原因及失败项修正 |
| 权限刷新 | 保存后整页进入加载状态，可能丢失结果视图 | 维护后的权限刷新在后台进行 |
| AI 运行参数 | 每条单独保存 | 一次保存所有已修改项，显示剩余未保存项并保留其输入 |
| 职位池配置 | 多组大表单持续展开 | 按名称和状态折叠查看，操作收进菜单；折叠时仍注册并保存完整字段，包括停用状态 |
| 快速导航 | 支持快捷打开，但缺少方向键定位和回车进入 | 补齐键盘选择、回车导航及当前项高亮 |
| W3 认证 | 独立欢迎/登录界面、开发令牌输入及失败重试按钮 | 自动进入 W3；失败仅显示原因与联系管理员提示，没有登录表单和重试按钮 |
| 已认证但无页面权限 | 默认页可能继续重定向到无权限页面 | 显示联系管理员配置权限的提示 |
| 小屏与辅助访问 | 隐藏操作与宽抽屉容易导致入口不可用 | 触屏显示更多入口、抽屉限于视口、键盘焦点样式、减弱动画偏好支持 |

候选人详情已有姓名入口、抽屉和明确的业务状态；数据看板已有卡片和图表；任务执行已有真实节点进度。这些有效结构继续使用，相关表格中的操作入口通过公共组件统一。业务流程中的下发、反馈、取消确认等仍按原有权限和业务条件执行。

## 批量编辑范围

- 岗位：招聘主体、部门、职位名称、对外名称、类别、岗位族、地点、学历、职责、专业、HC、对外发布；接收状态单独作为快捷操作。
- 院校：院校标签。
- 部门人员授权：部门、角色、转派能力、启用状态。姓名、工号和邮箱仍通过单条编辑维护。
- 用户：启用状态和 RBAC 角色集合；内置保护账号不可勾选。
- 角色：共同允许的权限集合。多值字段明确显示“整体替换”。
- 院校标签：启用状态；名称和默认标签仍通过单条维护。
- 院校准入规则：优先级、启用、第一/最高学历标签、最高学历范围。
- 专业大类与别名：说明、排序、所属大类、匹配方式、来源、备注、启用等共同字段。

## 交互约定

1. 表头勾选只选择当前页；跨页选择保留；修改列筛选后清空本表批量选择。
2. 打开侧边栏时固定本次记录清单。不会把未勾选的筛选结果自动纳入修改。
3. 先选择字段，再填写值；未选字段不发送；清空必须明确选择。单条字段和接收快捷操作直接展开。
4. 提交前展示记录数量与修改摘要。保存期间禁用关闭，避免丢失进行中的结果。
5. 批量维护逐条调用现有鉴权 PATCH 接口，每条独立保存，并非整个批次的单一事务。成功项保留，未成功项显示原因，可回到侧边栏修正。
6. 接收状态遇到版本变化，或者请求结果无法确认，需要刷新并重新选择记录；不会自动覆盖并发修改。
7. 所有数据修改仍由后端验证；前端隐藏或禁用操作不替代后端授权。

## 验证

- 项目 `make check build`：Go race 测试、vet、Go 构建、前端检查、发布工具测试及嵌入构建通过。
- 后续细节修正后再次执行 `make check-frontend build`，35 个前端测试文件、174 个用例全部通过；发布工具 11 个用例通过。
- 新增/扩展用例覆盖跨页选择、筛选后清空选择、明确空值、部分失败、认证过期停止后续写入、受保护账号、角色权限交集、W3 回调单次领取、认证失败无按钮、运行参数失败后保留输入及折叠配置保留停用状态。
- 使用当前真实前端代码和本地模拟 API，检查了桌面岗位表、更多菜单、单条编辑抽屉、批量接收摘要及保存结果，以及 390 像素宽度下的批量侧边栏和认证失败页。临时模拟入口已删除。

## 证据边界

未配置 `TEST_DATABASE_URL`、`TEST_REDIS_URL`，相应数据库/Redis 集成用例不构成本轮验证证据。浏览器检查使用模拟数据，未连接真实 W3，也未修改生产数据。浏览器自动检查不等同于用户人工视觉验收。

本轮没有更换前端框架或进行依赖大版本迁移；构建仍存在共享分块较大的提示。发布构建与附件校验结果由对应 Release 的验证记录提供。
