# v5.0.1

平台补丁版本，继续配套 Kernel v5.0.0、resume-contracts 5.0.0，面向 Linux amd64。

## 流程修复

- 修改或导入候选人的学历、专业、户籍、第一/最高学历院校后，撤销在途分析的提交资格，避免旧模型结果覆盖新资料；未归属的待分配资格同步变为待重新评估。
- 入池时冻结完整准入资料，独立分配再次检查；资料不一致或旧版快照缺字段时阻止分配，并同步简历状态为待重新评估。
- 试算不创建、绑定或领取正式分配工作项，也不在快照检查时改变资格。取消、失败、正常完成及发现失效资格的试算均不会阻断正式分配。

新增集成回归覆盖分析中修改、院校准入复核、表格导入、历史资格、已有部门归属、无关字段编辑，以及试算成功/取消/失败后的自动分配。原有 API 幂等和权限测试同步修正试算取消的预期。

## 安装与升级

使用 Release 中的四镜像离线安装包、配套 SHA-256 文件和安装指南。平台、Kernel、PostgreSQL 16、Redis 7 均包含在离线包中。W3 登录、模型连接和企业 CA 由现场配置。

v5.0.0 可备份后沿用数据库、上传文件卷、Compose 项目名和全部密钥升级；表结构和公开协议不变。升级前暂停处理计划和分配，结束在途任务；升级后对旧的未归属待分配候选人重新评估，再恢复自动任务。旧版资格缺少完整准入资料，不能直接用于新分配。已有部门归属、历史淘汰和任务记录不自动改写。

v4 及更早版本仍不支持原位升级。回退须使用匹配的程序、数据库及上传文件备份和原配置。完整操作以随包 `README-offline-deploy.md` 为准。

发布验证不等于生产部署；真实 W3、模型服务与企业 CA 链路须在目标环境另行验收。
